## Why does this repository qualify? (453/500 characters)

AI Keyboard is an actively maintained, privacy-first Android IME for Brazilian Portuguese. It combines local autocorrection with explicit, on-demand AI actions and encrypted storage for user-provided API keys. The alpha release has 88 JVM tests and CI, with ongoing work on security, accessibility, device testing, and Android compatibility. It addresses an underserved language ecosystem and the sensitive security challenges of AI-assisted text input.

## How will you use API credits? (442/500 characters)

We will use API credits to automate issue triage, reproduce Android and IME bugs, review pull requests, expand unit and instrumented tests, and analyze security-sensitive changes involving InputConnection, network requests, and API-key storage. Codex will also help maintain PT-BR correction quality, validate AI outputs, prepare releases, improve contributor documentation, and reduce maintenance time while keeping human review in the loop.

## Anything else we should know? (405/500 characters)

AI Keyboard is early-stage and transparent about its current adoption. The repository is public, MIT-licensed, has a tagged alpha release, CI, contribution and security policies, and a documented roadmap. Support would help turn a working foundation into a safer, better-tested open-source keyboard for Brazilian Portuguese users while establishing reusable practices for privacy-conscious AI input tools.
