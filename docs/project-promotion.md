## A) GitHub / dev communities

**AI Keyboard — an open-source Android keyboard for Brazilian Portuguese**

AI Keyboard is an open-source Android keyboard (Kotlin, `InputMethodService`) focused on Brazilian Portuguese. It does autocorrection **locally, on-device**, and adds optional AI writing actions (correct, rewrite, summarize, WhatsApp-style, translate) that run **only when you tap them**.

Privacy is a first-class goal and is verifiable in the code: no analytics, no telemetry, no ad SDKs, and **no API keys embedded in the build** (each user supplies their own key, stored encrypted on-device).

It's a practical codebase for anyone studying Android IME behavior, Kotlin, local autocorrection, or AI-assisted text transformation inside system input fields.

Status: **alpha** — it works and is unit-tested (88 tests, CI green), but still needs device testing, accessibility work, and polish. **Feedback and contributions are very welcome.**

👉 https://github.com/edu4rd04lv3s1/ai-keyboard
