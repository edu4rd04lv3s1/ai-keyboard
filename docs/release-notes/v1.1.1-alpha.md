# AI Keyboard v1.1.1-alpha

This is the first public alpha release of AI Keyboard after the open-source relaunch.

AI Keyboard is an Android keyboard for Brazilian Portuguese with local autocorrection,
privacy-first defaults, and optional on-demand AI writing actions.

## Highlights

- QWERTY Android IME implemented with `InputMethodService`.
- Local PT-BR autocorrection, suggestions, and slang-safe behavior.
- Field-aware typing policy for password, email, URL, and numeric fields.
- Explicit AI action bar for correction, rewriting, summarization, WhatsApp-style text,
  translation, and tone changes.
- Groq provider with optional Gemini fallback.
- User-entered API keys stored locally with encrypted storage.
- No API keys embedded in public builds.
- 88 JVM unit tests and GitHub Actions CI.
- MIT license, contribution guide, security policy, and public roadmap.

## Known limitations

- This is an alpha release and needs more device testing.
- Instrumented IME tests are not implemented yet.
- Public demo media is now tracked in the repository after the alpha tag.
- Accessibility review is pending.
- Release APK signing and distribution flow are not finalized.

## Verification

Local verification for this release:

```bash
./gradlew clean test
```

GitHub Actions also runs:

```bash
./gradlew test --stacktrace
```

## Security and privacy notes

- Local typing, local suggestions, and local autocorrection do not use the network.
- AI requests are sent only after an explicit user action.
- API keys are user-provided and stored with `EncryptedSharedPreferences`.
- Contributors should never commit secrets, local environment files, build outputs, APKs,
  or screenshots containing personal data.
